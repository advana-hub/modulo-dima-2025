# AA 2024/2025 | Data science for Business | DIMA @ UniGe

Benvenuti nel repository del materiale per il corso _Data science for Business_ (edizione 2025).

## Chi/Cosa/Quando

- __Docenti__: Davide Bisso, Samuele Fiorini, Silvio Lugaro
- __Ore indicative__: 24 (3 CFU)
- __Programma__: Introdurre la professione del Data Scientist in ambito business, inquadrando la natura ibrida della professione e fornendo i concetti di base delle principali metodologie, approcci e tecnologie utilizzati nell'ambito.
- __Periodo__: Marzo / Maggio 2025
 
Durante il corso verranno affrontati i seguenti argomenti:
 
- Introduzione alla Data Science.
- Modern Python per Data Scientist.
- Data Visualization.
- Tecniche e metodologie di analisi su un dataset reale.
- Una pipeline di Machine Learning end-to-end su dati testuali.
 
__Prerequisiti__ (nice-to-have, non bloccanti): Programmazione 2 (48382), Machine Learning (114944)
__Periodo__: Marzo/Maggio 2025
__Modalità d'esame__: colloquio orale
